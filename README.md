# wavewatch3-notes
This repository contains practical commands and workflows I used during my MSc thesis for running WaveWatch III simulations on HPC systems.

The goal is:
- to document commonly used terminal commands
- to explain *why* and *when* they are used
- to serve as a future reference for myself (and others)

## Contents
- `hpc_commands.md` – running, stopping, monitoring jobs
- `netcdf_tools.md` – inspecting and manipulating NetCDF files
- `wavewatch_workflow.md` – typical WW3 run logic
- `misc_tips.md` – things that saved me hours
